# ADR-0001: Godot + Nakama + PostgreSQL

Status: Accepted.

Use Godot 4.x for client and initial headless zone simulation. Use Nakama OSS for backend/social/persistence-facing APIs and PostgreSQL for durable storage.

Reason: open tooling, text-friendly project files, good fit for small-team AI-assisted development and no need for proprietary Royal Quest technology.
