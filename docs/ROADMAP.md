# Roadmap after bootstrap

## M0 — Foundation
Bootstrap, movement, camera, headless server, handshake.

## M1 — Network combat
Authoritative movement, monster replication, targeting, attack, death/respawn.

## M2 — Itemization
Loot tables, inventory, equipment, affixes, Echo Imprints.

## M3 — Persistence
Accounts, characters, inventory persistence, reconnect/idempotency.

## M4 — World slice
Town, field zone, quests, spawn manager, boss.

## M5 — Social dungeon
Party, chat, instance server, four-player dungeon.

## M6 — Economy
Trade, simple market, fees, audit ledger, anti-duplication tests.

## M7 — Closed alpha
Telemetry, load tests, original art pass, onboarding and balance.
